# Pre-work: 90–105 minutes

Pre-work is mandatory preparation but not a gate that excludes a student. Every item also needs an instructor fallback.

| Duration | Student activity | Evidence |
|---:|---|---|
| 15 min | Create or verify GitHub, Google/Colab, and Nscale access | Account checklist |
| 20 min | Review Python functions, type hints, JSON, HTTP, and environment variables | Five-question self-check |
| 15 min | Clone, branch, commit, pull, and push a small practice repository | Commit URL or screenshot |
| 20 min | Install VS Code and Cline; review plan/act, diff review, and approval safety | Cline setup screenshot |
| 15 min | Watch the practical mental model: LLM, RAG, tool, agent, MCP, fine-tuning, and eval | Decision-card answers |
| 10–20 min | Run the workshop health check | Machine-readable status output |

## Health check

The setup checker should verify without printing credentials:

```text
[ ] Python and pip/venv
[ ] Git and GitHub access
[ ] Starter repository cloned
[ ] Required Python packages import
[ ] Nscale service token is available through the environment
[ ] Nscale model list or test request succeeds
[ ] Cline opens and can access the starter repository
[ ] Local MCP test process can start
[ ] Colab notebook opens
[ ] Offline data and prepared index are present
```

## Pair formation

Form pairs before Day 1 when possible. Balance practical experience based on the setup self-check. Do not place all confident students together.

Each pair has:

- **Driver:** types and runs commands.
- **Navigator:** reads the checkpoint, predicts behavior, checks diffs, and records results.
- Swap roles every 20–30 minutes and record the swap in the lab sheet.
