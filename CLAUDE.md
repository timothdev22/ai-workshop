# Exercise Design

Build every lab as a ladder so early success motivates the next step:

- Start below the weakest pair's level - first step done in under 10 minutes by everyone, no setup or credentials in the way
- Every step must pay out something visible: a behavior change, a number that moved, a bug they diagnosed
- Build by extension, never restart - each step grows the same artifact so progress is obvious
- Give all information needed to solve the step (signatures, expected output shape, worked example, self-check); difficulty must come from thinking, never from missing information
- Raise difficulty gradually and state the acceptance criterion up front; keep genuinely unsupported problems as stretch tasks for fast finishers
